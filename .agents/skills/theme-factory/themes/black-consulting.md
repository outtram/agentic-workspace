# Black Consulting

Dark, modern consulting theme extracted from the AI Accelerated Engineering deck. Black backgrounds with bright accent pops — clean and high-impact.

## Color Palette

- **Black**: `#000000` - Primary background (dark slides)
- **White**: `#FFFFFF` - Primary text on dark backgrounds
- **Azure Blue**: `#00B0F0` - Primary accent, highlights, callouts
- **Amber Gold**: `#FFC000` - Secondary accent, emphasis, status
- **Green**: `#00B050` - Tertiary accent, success indicators
- **Red**: `#FF0000` - Alert, warning emphasis
- **Dark Grey**: `#313131` - Subtle text on light backgrounds

### Theme Palette (Office base)

- **Steel Blue**: `#4F81BD` - Theme accent 1
- **Terracotta**: `#C0504D` - Theme accent 2
- **Olive**: `#9BBB59` - Theme accent 3
- **Purple**: `#8064A2` - Theme accent 4
- **Teal**: `#4BACC6` - Theme accent 5
- **Tangerine**: `#F79646` - Theme accent 6

## Typography

- **Headers**: Open Sans ExtraBold
- **Subheaders**: Open Sans (Regular)
- **Body Text**: Open Sans Light
- **Fallback**: Aptos, Calibri

### Size Guide

| Element | Size |
|---------|------|
| Slide title / hero text | 24-30pt ExtraBold |
| Subheader | 18-20pt Regular |
| Body text | 14-19pt Light |
| Supporting text | 12-14pt |

## Layout Characteristics

- **Slide format**: 16:9 widescreen (13.3" x 7.5")
- **Dark-dominant** — black backgrounds with white text
- **Image-heavy divider slides** — full-bleed imagery with text overlay
- **Clean, minimal content** — fewer words, bigger impact
- **High contrast accents** — bright blue/gold/green pops on dark

## Slide Layout Types

| Layout | Usage |
|--------|-------|
| Title Slide - Black | Opening/cover slide |
| Content_Black_Blank | Primary content (most common) |
| 2_Divider slide with image | Section dividers with imagery |
| Section Header | Chapter breaks |
| Blank | Flexible/custom layouts |

## Best Used For

AI strategy decks, engineering presentations, technology showcases, innovation pitches, executive briefings on dark backgrounds.
