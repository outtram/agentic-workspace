# Super Fund

Theme extracted from the Member Platform STR deck. Bold warm accents (ember orange, deep purple, coral) on clean, structured consulting layouts.

## Color Palette

- **Charcoal**: `#2E2E2E` - Primary text and dark elements
- **Deep Purple**: `#260046` - Section headers, dark accents, hyperlinks
- **Ember Orange**: `#EA4403` - Primary accent, callouts, emphasis
- **Coral Red**: `#F06C5A` - Secondary accent, highlights, followed links
- **Sunburst Yellow**: `#FFE100` - Tertiary accent, status indicators
- **Warm Sand**: `#EDE1B5` - Soft background tints, cards
- **Mid Grey**: `#606060` - Supporting text, captions
- **Light Grey**: `#DFE1DF` - Subtle backgrounds, dividers
- **Off-White**: `#F9F9F9` - Card/panel backgrounds
- **White**: `#FFFFFF` - Primary background

### Shape/Fill Tints (for cards and panels)

- **Warm Blush**: `#FCE2DE` / `#FEF4F2` / `#FFF2EE` - Ember-tinted light fills
- **Soft Lavender**: `#F7EDFF` / `#FCF8FF` - Purple-tinted light fills
- **Pale Lemon**: `#FFF499` / `#FFF9CD` - Yellow-tinted light fills

## Typography

- **Headers**: Arial (Bold)
- **Body Text**: Arial (Regular)
- **Fallback**: Verdana, Open Sans

### Size Guide

| Element | Size |
|---------|------|
| Slide title | 14-18pt bold (compact consulting style) |
| Section header | 10-12pt bold |
| Body text | 7-10pt |
| Captions/footnotes | 5-6pt |
| Large callout numbers | 54-66pt |

## Layout Characteristics

- **Slide format**: 16:9 widescreen (13.3" x 7.5")
- **Dense information layouts** — consulting-style with high content density
- **Capability summary cards** — structured assessment panels
- **Section dividers** — bold section header slides
- **Content-heavy** — tables, grids, multi-column layouts

## Slide Layout Types

| Layout | Usage |
|--------|-------|
| Title Slide | Opening/cover slide |
| Title and Content | Primary content (most common) |
| Section Header | Chapter dividers |
| Capability Summary | Assessment cards (one-up and half variants) |
| Thank You | Section closers, appendix headers |
| Text and RH pic | Text with right-hand image |

## Best Used For

Strategy decks, technology assessments, capability maturity reviews, consulting deliverables, roadmap presentations, current-state analyses.
