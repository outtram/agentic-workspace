# White Consulting

Clean, light consulting theme extracted from the GTM deck. White backgrounds with purple accent pops and teal highlights — polished and professional.

## Color Palette

- **Black**: `#000000` - Primary text
- **White**: `#FFFFFF` - Primary background, card fills
- **Purple**: `#7030A0` - Primary accent, emphasis, callouts
- **Teal**: `#4EC4B3` / `#3DB5A9` - Secondary accent, highlights
- **Light Teal**: `#CFEBE6` - Tinted card backgrounds
- **Amber Gold**: `#FFC000` - Tertiary accent, status indicators
- **Light Grey**: `#E7E7E7` - Borders, dividers, subtle fills
- **Off-White**: `#F2F2F2` - Panel backgrounds

### Theme Palette (Office base)

- **Blue**: `#4472C4` - Theme accent 1
- **Orange**: `#ED7D31` - Theme accent 2
- **Grey**: `#A5A5A5` - Theme accent 3
- **Gold**: `#FFC000` - Theme accent 4
- **Sky Blue**: `#5B9BD5` - Theme accent 5
- **Green**: `#70AD47` - Theme accent 6

## Typography

- **Headers**: Open Sans ExtraBold
- **Subheaders**: Open Sans SemiBold
- **Body Text**: Open Sans (Regular)
- **Light Body**: Open Sans Light
- **Fallback**: Calibri

### Size Guide

| Element | Size |
|---------|------|
| Slide title | 27pt ExtraBold |
| Section header | 14-16pt ExtraBold |
| Body text | 9-10pt Regular |
| Detail/fine text | 7-8pt |
| Master heading | 10-18pt |

## Layout Characteristics

- **Slide format**: 16:9 widescreen (13.3" x 7.5")
- **Light-dominant** — white backgrounds with dark text
- **Breadcrumb navigation** — slide headers with section trail
- **Content-rich** — structured grids and multi-section layouts
- **Clean card panels** — white or light grey fill with subtle borders

## Slide Layout Types

| Layout | Usage |
|--------|-------|
| 00_Cover | Opening slide |
| Title and Subhead (Breadcrumbs) | Primary content with navigation |
| Title and Content (Opt 1/2) | Standard content variants |
| Heading and Breadcrumbs | Section headers |
| Quote | Pull quotes / key messages |
| Blank | Flexible/custom layouts |
| EndCover | Closing slide |

## Best Used For

Go-to-market strategy, vendor assessments, implementation plans, white-background consulting deliverables, client-facing proposals.
