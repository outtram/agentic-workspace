# Heartbeat Checklist

## Every Check (every 30 minutes)
- Check for approaching deadlines (next 2 hours)
- Check for overdue reminders
- Check if any scheduled meetings are starting soon

## Morning (7am - 10am)
- Preview today's calendar
- List any due or overdue tasks
- Flag anything that needs prep before first meeting

## Midday (11am - 1pm)
- Check afternoon calendar for conflicts
- Remind about any tasks promised for "today"

## Evening (5pm - 7pm)
- Review tomorrow's schedule
- Flag anything that needs overnight attention
- Summarise what got done today (if asked)

## Importance Criteria
Only notify if:
- A meeting is starting in the next 15 minutes
- A deadline is today or overdue
- Something urgent came in (marked high priority)
- A task that was explicitly requested is now complete

Do NOT notify for:
- Routine calendar events already acknowledged
- Low-priority tasks with distant deadlines
- "Nothing to report" updates
- Information Troy can see himself in the dashboard
