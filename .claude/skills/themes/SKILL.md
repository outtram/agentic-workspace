# Themes Skill

Custom theme definitions for presentations, documents, and dashboards.

## Available Themes

- **black-consulting** — Dark, modern consulting theme. Black backgrounds with bright accent pops.
- **white-consulting** — Light, clean consulting theme.
- **super-fund** — Super fund / financial services theme.

## Usage

When a theme is requested, read the relevant theme file from this directory and apply its colour palette, typography, and layout rules to the target artifact.

Theme files:
- `black-consulting.md`
- `white-consulting.md`
- `super-fund.md`
