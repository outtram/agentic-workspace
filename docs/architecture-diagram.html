How You Use It
Four Entry Points
Claude Code for task management + agents. OutBot for chat, memory, email, and daily review. Cursor for coding.
# Claude Code (agents + pipelines)
claude
cd ~/CODE/AAGLOBAL && claude
# OutBot CLI (chat + memory + email + daily review)
outbot
cd ~/CODE/AAGLOBAL && python brain/chat.py
# OutBot Voice
outbot voice
cd ~/CODE/AAGLOBAL && python brain/chat.py --voice
# OutBot Telegram (mobile + heartbeat)
cd ~/CODE/AAGLOBAL && python brain/main.py
# Cursor (coding + editing)
Open ~/CODE/AAGLOBAL in Cursor IDE
powered by Claude CLI (Max plan)
System 1 — Task Management
Claude Code Agents
9 agents orchestrated by the Overseer. Run from terminal with claude. Say "do my daily review" to trigger the pipeline.
Daily Pipeline:
Import Reminders → Enrich Tasks → Wrangle Overdue → Dashboard
All Agents:
Overseer Reminders Importer Work Item Enricher Overdue Wrangler Dashboard Generator Work Tracker Memory Writer Navigator Updater Meta Agent
System 2 — Conversational AI
OutBot
Chat with personality, memory, email, and daily review. Works via CLI, voice, or Telegram. The "always reachable" layer.
Daily Review (shared workflow):
Sync Reminders → Check Overdue → Dashboard → Update Gist
Entry Points:
CLI Chat Voice Mode Telegram Bot
Capabilities:
Daily Review Remember Recall Reflection Gmail Inbox Gmail Outbox Personality (SOUL.md) Session Continuity Heartbeat (Telegram)

Shared File System
The Brain — .claude/
File-native memory system. Both Claude Code agents and OutBot read/write here. Changes from one are visible to the other.
memory/

work/

agents/

workflows/
