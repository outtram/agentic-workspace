Build Roadmap

Implementation phases.

Complete
Phase 01
Shell (the container)
Textual app with 2-column layout, 3×3 tile grid with quadrant colours, arrow/number navigation, pagination, space to select, today shortlist in context panel.
app.py tile_grid.py context_panel.py command_bar.py status_bar.py task_loader.py
Complete
Phase 02
Brain (command bar + OutBot)
Command bar accepts text input, intent router parses natural language vs /slash vs :filters, Claude responses in context panel, brain logger records actions.
router.py brain_logger.py handlers/triage.py handlers/enrich.py
Complete
Phase 03
Voice + Predictions
Voice mode toggle with v key, Whisper transcription, URL task detection + research handler, brain predictions on launch based on patterns.
handlers/voice.py handlers/research.py predictions.py
Complete
Phase 04
Polish + Agents/Skills
All agents invocable via /agent, email drafting, Telegram bridge, help overlay, error handling, Task Focus view, Command Palette.
handlers/agent_runner.py handlers/email.py telegram_bridge.py task_focus.py command_palette.py
Complete
Phase 05
Heartbeat, Memory, Chat
Chat panel (c key toggle), heartbeat bridge for proactive nudges, /remember and /forget commands, help_data.yml single source of truth, quick sync with AppleScript whose clause.
heartbeat_bridge.py handlers/memory.py help_data.yml help_gen.py
